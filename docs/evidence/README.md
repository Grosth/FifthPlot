# Evidencias de FifthPlot

Las capturas verificables se guardan en `docs/evidence/screenshots/`, agrupadas por etapa. Cada imagen debe corresponder a la interfaz o a una ejecución real del proyecto y llevar una nota en `index.md` que indique qué muestra y qué no permite concluir.

## Reglas de registro

- No crear, retocar ni reconstruir capturas, resultados, salidas de terminal o marcas de tiempo.
- Guardar el PNG original de la captura y anotar la fecha que muestre la herramienta al capturarla; si no se muestra, no inventar una.
- No registrar pruebas ejecutadas por Codex. Registrar solo ejecuciones supervisadas o hechas manualmente por el estudiante, indicando cuál de las dos fue.
- Registrar errores observados y su corrección sin atribuir supervisión estudiantil si no ocurrió.
- Distinguir claramente entre evidencia de interfaz, ejecución parcial y resultado completo.
- Antes de incluir evidencia en el informe o video, verificar que corresponda a los archivos y al estado real de FifthPlot.

## Etapas y nombres

Usar carpetas breves bajo `screenshots/` y nombres descriptivos, por ejemplo:

~~~text
screenshots/
  01-interfaz/
    fifthplot-formulario-inicial.png
  02-historia/
    cuento-cinco-escenas-<fecha-real>.png
  03-ilustraciones/
    estrategia-ip-adapter-<fecha-real>.png
  04-audio/
    narracion-y-ambiente-<fecha-real>.png
  05-integracion/
    cuento-completo-<fecha-real>.png
~~~

No crear archivos de imagen vacíos ni capturas de muestra. Las carpetas de etapas pendientes se crean cuando exista evidencia real para guardar.

## Índice

Consulta [index.md](index.md) para las capturas existentes y las etapas pendientes, [incidencias.md](incidencias.md) para las incidencias observadas y [ficha-ejecucion-manual.md](ficha-ejecucion-manual.md) para registrar únicamente ejecuciones manuales o directamente supervisadas por el estudiante.

Los informes, reportes de prompts y copias fuente que ya existían en `docs/evidence/` se conservan como historial del prototipo previo. Mantienen su contenido y no se reinterpretan como capturas ni como resultados del flujo reconstruido hasta verificarlos contra la versión actual.
